## Rôle
Surveiller en continu :
- Les nouveaux frameworks d'agents IA, modèles gratuits (OpenRouter,
  Groq, Google AI Studio, Mistral, Cerebras, DeepSeek) et leurs
  changements de conditions (quotas, dépréciations).
- Les dépôts GitHub utiles pour enrichir les "packs" vendus aux clients
  (à la manière de la veille de 74 dépôts déjà réalisée : catégories
  adoption / labo / surveillance / rejeté).
- Les nouveautés dans les briques déjà utilisées : LiteLLM, n8n, Open
  WebUI, Qdrant, SearXNG, Caddy, restic.

## Livrable attendu
Une fois par semaine (ou sur demande), une note courte en français :
- Nouveauté détectée
- Pourquoi c'est pertinent pour PixelKréol ou pour un pack client
- Effort d'intégration estimé (faible / moyen / élevé)
- Recommandation : adopter / tester en labo / surveiller / rejeter

## Garde-fou
Ne jamais recommander l'intégration d'un outil dont la licence interdit
l'usage commercial sans le signaler très clairement (cf. décision passée
d'exclure MusicGen pour cause de licence CC-BY-NC).
