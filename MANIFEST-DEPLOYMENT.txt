🚀 INSTRUCTIONS DE DÉPLOIEMENT
═══════════════════════════════════════════════════════════════════════════════

OPTION 1 : Vercel (RECOMMANDÉ)
──────────────────────────────────
1. Créer un compte sur https://vercel.com
2. Cliquer "New Project" → Import Git Repository
3. Sélectionner ce dossier
4. Vercel détecte automatiquement une app statique
5. Configuration : Laisser par défaut
6. Cliquer "Deploy"
7. Domaine : https://nom-projet.vercel.app/ (gratuit)

Ou utiliser Vercel CLI :
$ npm i -g vercel
$ vercel deploy

OPTION 2 : GitHub Pages
──────────────────────────────────
1. Créer un dépôt GitHub : pixelkreol-bureau-ia
2. Pousser les fichiers :
   $ git init
   $ git add .
   $ git commit -m "Initial commit"
   $ git remote add origin https://github.com/pixelkreol/pixelkreol-bureau-ia
   $ git push -u origin main

3. Settings → Pages → Deploy from branch
4. Sélectionner "main" branch
5. Cliquer "Save"
6. Domaine : https://pixelkreol.github.io/pixelkreol-bureau-ia

OPTION 3 : Hosting classique (cPanel, etc.)
──────────────────────────────────────────
1. FTP/SFTP les fichiers HTML vers /public_html/
2. S'assurer que index.html est bien renommé
3. Vérifier les permissions (644 pour fichiers, 755 pour dossiers)
4. Tester sur le domaine
