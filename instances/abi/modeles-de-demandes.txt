MODÈLES DE DEMANDES — Bureau IA d'ABI Holding (instance de TEST, données fictives) — 10 modèles
====================================================================
Chaque modèle donne : un titre, l'agent à choisir (nom EXACT du modèle dans Open WebUI) et un texte à copier.
Remplacez ce qui est entre crochets [ ... ]. Aucun montant ni taux n'est écrit ici.
Pour une demande qui ne ressemble à aucun modèle, écrivez « améliore ma demande : … » au Spécialiste Prompt
(pk-10-specialiste-prompt) : il choisit l'agent et réécrit la demande.

Comment les enregistrer dans Open WebUI (à la main, ~1 minute par modèle) :
  Espace de travail > Prompts > « + » > titre = le titre du modèle ; commande = un mot court précédé de « / » (par exemple /appel-de-fonds) ;
  contenu = le texte à copier.
  Remarque : le format d'un fichier d'import n'a pas pu être vérifié pour la version d'Open WebUI de cette instance ; aucun fichier d'import n'est donc fourni.

--------------------------------------------------------------------
1. Lettres d'appel de fonds
Agent recommandé : pk-04-appels-de-fonds
Texte à copier (remplacez ce qui est entre crochets) :
```
Contexte : programme [nom du programme], [nombre] lots, jalon atteint : [jalon].
Tâche : préparer les lettres d'appel de fonds pour ce jalon.
Ce que je te donne : l'attestation d'avancement [coller], le tableau des acquéreurs et des montants déjà payés [coller].
Forme du résultat : une lettre type puis un tableau acquéreur | lot | montant à appeler.
Limites : aucun taux ni plafond inventé : ceux de l'échéancier fourni ; Feu : ROUGE, la direction valide avant tout envoi.
```
