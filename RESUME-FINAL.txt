OPTION A : VERCEL (RECOMMANDÉ - le plus simple)
──────────────────────────────────────────────────
1. Créer compte sur vercel.com
2. Cliquer "New Project"
3. Uploader le dossier scratchpad/
4. Laisser les paramètres par défaut
5. Cliquer "Deploy"
6. C'est fait ! Lien : https://votre-projet.vercel.app

Avec CLI :
$ npm install -g vercel
$ cd scratchpad/
$ vercel

OPTION B : GITHUB + GITHUB PAGES (gratuit aussi)
──────────────────────────────────────────────────
1. Créer dépôt GitHub : pixelkreol-bureau-ia
2. Pousser les fichiers :
   $ git init
   $ git add .
   $ git commit -m "Initial commit"
   $ git remote add origin https://github.com/USER/pixelkreol-bureau-ia
   $ git push -u origin main

3. Settings → Pages → Deploy from branch "main"
4. URL : https://USER.github.io/pixelkreol-bureau-ia

OPTION C : HOSTINGER / HOSTING CLASSIQUE
──────────────────────────────────────────────
1. FTP les fichiers vers /public_html/
