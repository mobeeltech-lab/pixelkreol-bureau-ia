MODÈLES DE DEMANDES — Bureau IA PixelKréol (15 modèles)
====================================================================
Chaque modèle donne : un titre, l'agent à choisir (nom EXACT du modèle dans Open WebUI) et un texte à copier.
Remplacez ce qui est entre crochets [ ... ]. Rien n'est chiffré ici : les prix viennent toujours de l'agent Devis.
Données d'exemple fictives. Pour une demande qui ne ressemble à aucun modèle, écrivez « améliore ma demande : … »
au Spécialiste Prompt (pk-34-specialiste-prompt) : il choisit l'agent et réécrit la demande.

Comment les enregistrer dans Open WebUI (à la main, ~1 minute par modèle) :
  Espace de travail > Prompts > « + » > titre = le titre du modèle ; commande = un mot court précédé de « / » (par exemple /devis-vitrine) ;
  contenu = le texte à copier. Ensuite, dans une conversation, tapez la commande pour insérer le texte.
  Remarque : le format d'un fichier d'import n'a pas pu être vérifié pour la version 0.12.0 ; aucun fichier d'import n'est donc fourni.

--------------------------------------------------------------------
1. Devis d'un site vitrine
Agent recommandé : pk-04-devis
Texte à copier (remplacez ce qui est entre crochets) :
```
Contexte : je prépare un devis pour [nom du client], [activité], à [ville].
Tâche : chiffrer un site vitrine de [nombre] pages avec la grille de PixelKréol et proposer l'échéancier.
Ce que je te donne : le besoin du client : [pages et fonctions voulues], [délai souhaité]. Si une information manque, liste-la d'abord.
Forme du résultat : devis poste par poste avec total HT, TVA à confirmer selon la région, acompte et échéancier.
Limites : aucune remise, aucun prix hors grille ; Feu : ORANGE (je valide avant l'envoi au client).
```
